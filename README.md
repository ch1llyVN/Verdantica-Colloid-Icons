# To install the icon theme:
>1. Open the Base folder, extract it


>2. Open the Accent-Packs folder, choose your accent - there are 28 options to choose


>3. Extract the accent zip file, open the icons folder, move it to the Base folder, merge two copy to the base


>4. Copy/Move 2 Base icon pack to ~/.icons


>5. To use light theme select Solstice | To use dark theme select Nocturne
# You can preview the hex code of color palette in the palettes folder
