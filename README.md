# To install the icon theme:
> Open the Base folder, extract it


> Open the Accent-Packs folder, choose your accent - there are 28 options to choose


> Extract the accent zip file, open the icons folder, move it to the Base folder, merge two copy to the base


> Copy/Move 2 Base icon pack to ~/.icons


> To use light theme select Solstice | To use dark theme select Nocturne
# You can preview the hex code of color palette in the palettes folder
